# API17 for Mac

One-click setup for **Codex** and **Claude Code** on your [API17](https://www.api17.cn) balance.

1. Download the app from the [latest release](https://github.com/yunfan888888/api17-desktop/releases/latest)
   - `API17-mac-apple-silicon.dmg` — Macs with M1 / M2 / M3 / M4 chips
   - `API17-mac-intel.dmg` — Macs with Intel processors
2. Sign in with Google
3. Click **Connect** next to Codex or Claude Code, then restart it

Click **Disconnect** any time to restore your original settings.

Not sure which Mac you have? Apple menu → About This Mac. "Chip: Apple M…" means Apple silicon; "Processor: Intel…" means Intel.

This repository only hosts the signed and notarized installers.
